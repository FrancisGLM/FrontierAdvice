ESTRUCTURA DE DATOS DE STRAPI (FRONTIER ADVICE)

A continuación se detalla la lista de tablas (Collection Types) existentes en el backend de Strapi, junto con sus campos respectivos.

Nota: Actualmente no existen componentes personalizados (Components) creados en Strapi (el directorio src/components no existe).

==================================================
TABLAS (COLLECTION TYPES)
==================================================

1. PasoFronterizo (paso_fronterizos)
   - nombre_oficial (string)
   - region (string)
   - habilitado_para (json)
   - codigo_fuente (string)
   - latitud (float)
   - longitud (float)
   - altitud (integer)
   - activo (boolean)
   - clima_actuals (relación: One-to-Many con ClimaActual)

2. ClimaActual (clima_actuals)
   - paso_fronterizo (relación: Many-to-One con PasoFronterizo)
   - temperatura_actual (decimal)
   - humedad_actual (integer)
   - viento_actual (decimal)
   - precipitacion_actual (decimal)
   - weathercode (integer)
   - descripcion_actual (string)
   - nivel_riesgo_actual (enumeration: "Bajo", "Medio", "Alto")
   - pronostico_3dias (json)
   - capturado_en (datetime)

3. EstadoDiario (estado_diarios)
   - id_paso (relación: One-to-One con PasoFronterizo)
   - fecha_reporte (datetime)
   - estado_general (string)
   - fuente (string)
   - mensaje_original (text)
   - creado_en (datetime)
   - origen_tipo (string)
   - horario_apertura (string)
   - horario_cierre (string)
   - dias_operacion (json)
   - motivo_estado (string)
   - nivel_riesgo_calc (enumeration: "alto", "medio", "bajo", "null")
   - tipo_vehiculos (json)
   - msg_timestamp (biginteger)
   - msg_id_waha (string)
   - msg_server_id (integer)
   - confianza_extraccion (decimal)
   - fecha_vigencia_desde (datetime)
   - fecha_vigencia_hasta (datetime)
   - es_programado (boolean)

4. AlertaEvento (alerta_eventos)
   - idpaso (relación: One-to-One con PasoFronterizo)
   - tipo_alerta (string)
   - fecha_evento (datetime)
   - descripcion (text)
   - fuente (string)

5. MensajeWAHA (mensaje_wahas)
   - id_estado (relación: One-to-One con EstadoDiario)
   - msg_id_waha (string, unique)
   - msg_body (biginteger)
   - msg_timestamp (biginteger)
   - msg_fecha_iso (datetime)
   - msg_server_id (integer)
   - msg_row_id (integer)
   - procesado (boolean)
   - relevante (boolean)
   - fuente (string)

6. Restriccion (restriccions)
   - id_estado (relación: One-to-One con EstadoDiario)
   - tipo_restriccion (string)
   - descripcion (text)

7. SenalPredictiva (senal_predictivas)
   - id_paso (relación: One-to-One con PasoFronterizo)
   - horizonte_horas (integer)
   - nivel_riesgo (enumeration: "Alto", "Medio", "Bajo")
   - motivo_resumen (text)
   - fecha_calculo (datetime)
   - tipo_evento (string)
   - datos_entrada (json)

8. tweet-x (tweet_xes)
   - tweet_id_x (string, required)
   - tweet_text (text)
   - tweet_date (datetime)
   - tweet_url (string)
   - fuente (string)
   - relevante (boolean)
   - procesado (boolean)
